# Student presentations

Upload your presentation to the folder of its module, as a PDF:

| Folder | Module |
|---|---|
| [`benchmarks/`](benchmarks/) | Benchmarks |
| [`harness/`](harness/) | Harness |
| [`ai-safety/`](ai-safety/) | AI Safety |
| [`post-training/`](post-training/) | Post-Training |

**File name:** the title of the paper or talk, for example `swe-bench-verified.pdf`. No need to add your name.

## How to submit

1. Open your module's folder on GitHub and click **Add file → Upload files**.
2. Drop in your PDF and click **Propose changes**, then **Create pull request**.
